What is hcax?

hcax is a high-ratio lossless archive tool written in pure Go. It combines CDC chunking with content-defined dedup, solid streams, content-adaptive preprocessing (BMP/TGA/PNM reversible transforms, text detection) and context-mixing prediction to squeeze out smaller archives than classic general-purpose compressors — with no native dependencies (only max/ultra optionally shell out to xz).

Five modes cover the speed–ratio spectrum: fast → best → max → ultra → text.

max / ultra require the system xz command (brew install xz); without it hcax falls back to pure-Go lzma2 and the ratio degrades from 26.89% to 33.40% (~24% larger archive). The other three modes are pure Go, no deps.

Install from source

git clone https://github.com/Fleeting-Starfall/hcax.git
cd hcax
go build -o hcax .
./hcax --help

Quick start

# Pack (default: best mode)
hcax pack out.hcax <file-or-dir>...

# Choose a mode
hcax pack backup.hcax ~/Documents -m max

# Unpack and verify
hcax unpack out.hcax /path/to/output
hcax verify out.hcax

See the repository README for full documentation.
